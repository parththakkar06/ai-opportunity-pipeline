# Sample exports (demo data)

These files come from **demo mode** (`python scripts/demo_api.py`): the real pipeline and export code, run on
fixture data for a fictional company, "Maple Street Dental". No model or search calls were made, and the
figures are illustrative.

| File | What it is |
|---|---|
| `demo-maple-street-dental-pitch.pdf` | The one-page CEO pitch, exactly as `Export → One-page pitch` produces it |
| `demo-maple-street-dental-report.pdf` | The full report: cover with the verifier pass rate, the 5 sections, numbered dated sources |
| `demo-maple-street-dental-deck.pptx` | The 10-slide pitch deck with speaker notes |

The earlier Sobha sample was removed: it predated the provenance checks and addressed a former managing
director, the failure described in `docs/APPROACH.md` §5.
